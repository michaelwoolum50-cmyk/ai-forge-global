# AI Forge — Belajar AI Sambil Bermain (Indonesia)

**Forge prompts into products.**

AI Forge adalah game belajar untuk orang biasa usia 18–55 yang ingin memakai AI dengan lebih baik — tanpa kursus teknis, tanpa ceramah. Kamu bermain, mengambil tantangan, dan menempa prompt menjadi produk. Skill prompt tumbuh lewat permainan, bukan lewat hafalan.

## Fitur
- Beranda (Home) · Tantangan (Challenges) · Bermain (Play) · Forge talk
- Panduan menempa (Forging guide) · Pengaturan (Settings) · Pengingat (Reminders)
- Umpan balik di dalam aplikasi · Manual di dalam aplikasi · Cadangan / pemulihan lokal

## Privasi
Semua data tetap di perangkatmu — tanpa akun, tanpa cloud.
