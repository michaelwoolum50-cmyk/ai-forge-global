# AI Forge — Matuto ng AI Habang Naglalaro (Pilipinas)

**Forge prompts into products.**

Ang AI Forge ay isang learning game para sa pangkaraniwang tao edad 18–55 na gustong gumamit ng AI nang mas mahusay — walang technical course, walang mahabang lecture. Maglalaro ka, tatanggap ng challenges, at ifo-forge ang prompts hanggang maging produkto. Lumalago ang prompt skill sa paglalaro, hindi sa pagkakabisa.

## Mga feature
- Home · Challenges · Play · Forge talk
- Forging guide · Settings · Reminders
- In-app feedback · In-app manual · Local backup / restore

## Privacy
Lahat ng data ay nananatili sa device mo — walang account, walang cloud.
