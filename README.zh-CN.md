# AI Forge — 在游戏中学习 AI（中国）

**Forge prompts into products.**

AI Forge 是一款为普通用户（18–55 岁）设计的益智学习游戏，让你更熟练地使用 AI——没有技术课程，没有长篇讲解。你通过游玩、接受挑战，把提示词锻造为产品。提示词技能在游玩中成长，而不是靠死记硬背。

## 特色功能
- 主页（Home）· 挑战（Challenges）· 游玩（Play）· Forge talk
- 锻造指南（Forging guide）· 设置（Settings）· 提醒（Reminders）
- 应用内反馈 · 应用内手册 · 本地备份/恢复

## 隐私
所有数据都保留在你的设备上——没有账号，没有云端。
