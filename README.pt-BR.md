# AI Forge — Aprenda IA Jogando (Brasil)

**Forge prompts into products.**

O AI Forge é um jogo de aprendizado para pessoas comuns de 18 a 55 anos que querem usar IA melhor — sem curso técnico, sem aula chata. Você joga, aceita desafios e forja prompts até virarem produtos. A habilidade com prompts cresce jogando, não decorando.

## Recursos
- Início (Home) · Desafios (Challenges) · Jogar (Play) · Forge talk
- Guia de forja (Forging guide) · Configurações (Settings) · Lembretes (Reminders)
- Feedback dentro do app · Manual dentro do app · Backup / restauração local

## Privacidade
Todos os dados ficam no seu aparelho — sem contas, sem nuvem.
